# Учебный frontend-проект

## Описание

Проект выполняется в рамках дисциплины «Фронтенд и бэкенд разработка».

Проект представляет собой учебный многостраничный сайт интернет-магазина или каталога услуг. В рамках практических занятий проект будет постепенно расширяться и дополняться новыми страницами и функциональностью.

## Структура проекта

- `index.html` — главная страница проекта;
- `css/style.css` — файл стилей;
- `images/` — папка для изображений;
- `.gitignore` — список файлов и папок, исключённых из Git;
- `README.md` — описание проекта.

## Используемые технологии

- HTML;
- CSS;
- Git;
- GitHub;
- GitHub Pages.
