# Канцтовары

Учебный магазин для практики 5.

## Запуск

`python3 -m http.server 8817 --bind 127.0.0.1`

## Выполнено

Главная, каталог и контакты; единая навигация, якоря, хлебные крошки, уникальные title и meta description.

Система именования БЭМ будет применена отдельным этапом практики 7.
