# Канцтовары

## Описание проекта

Учебный интернет-магазин по дисциплине «Фронтенд и бэкенд разработка». На главной и в каталоге представлены тетрадь, папка, ручка и карандаш. Реализованы общая навигация, якорные ссылки, хлебные крошки, фильтры каталога и модальная форма заявки.

Товары и цены демонстрационные. Форма проверяет данные в браузере и показывает учебное подтверждение; реальная отправка на сервер отсутствует.

## БЭМ структура проекта

| Блок | Назначение |
| --- | --- |
| `site-header` | Шапка сайта |
| `site-nav` | Основная навигация |
| `breadcrumbs` | Хлебные крошки |
| `hero` | Вводный блок главной страницы |
| `products-grid` | Сетка товаров |
| `product-card` | Повторяемая карточка товара |
| `catalog-layout` | Раскладка каталога |
| `catalog-filters` | Боковой блок фильтров |
| `order-dialog` | Модальное окно |
| `order-form` | Форма заявки |
| `button` | Общая кнопка |
| `site-footer` | Подвал сайта |

Дополнительные блоки: `section`, `advantages`, `aside-info`, `catalog-products`, `filters-form`, `success-message` и `contact-details`.

Примеры элементов: `site-nav__list`, `product-card__title`, `product-card__price`, `order-form__input`. Примеры модификаторов: `product-card--writing`, `button--primary`, `button--secondary`. Модификатор применяется вместе с базовым классом: `button button--primary`.

## Как проверить

Открыть сайт на GitHub Pages, перейти между тремя страницами, проверить якоря, фильтры и форму. В DevTools посмотреть Flexbox/Grid, классы БЭМ и состояния фокуса.

Для локального просмотра из папки проекта:

```sh
python3 -m http.server 8817 --bind 127.0.0.1
```

Адрес: `http://127.0.0.1:8817/`.

## Выбранные задачи для практики 8 и КР №2

Пункты выбраны из раздела 14 методички практического занятия №8. Это план самостоятельных доработок; ниже не перечисляются уже выполненные изменения. Доработки дополняют обязательные требования соответствующей контрольной работы.

### Практическое занятие 8 — доработки текущего сайта для КР №1

1. **Блок часто задаваемых вопросов.** Добавить FAQ о выборе товаров и заполнении учебной заявки; раскрытие ответов через HTML `details` и `summary`.
2. **Расширенная таблица характеристик или сравнения.** Добавить таблицу сравнения четырёх товаров по категории, назначению и демонстрационной цене.
3. **Фиксированная кнопка «Наверх».** Добавить ссылку на начало страницы с `position: fixed` и видимым клавиатурным фокусом.
4. **Sticky-фильтр каталога.** Закрепить блок фильтров при прокрутке на широком экране через `position: sticky`; на узком оставить обычное расположение.

### Следующая контрольная работа — КР №2 на Bootstrap

КР №2 выполняется в отдельном репозитории `kr2-bootstrap-shop` и сохраняет тематику канцтоваров. Эти четыре пункта дополняют обязательную реализацию страниц и компонентов на CSS-фреймворке.

1. **Расширенный каталог товаров.** Увеличить ассортимент до восьми демонстрационных товаров и разместить их через сетку Bootstrap.
2. **Страница отдельной категории.** Добавить `category.html` для категории «Для письма» с отдельным списком товаров, навигацией и хлебными крошками.
3. **Несколько вариантов карточек через БЭМ-модификаторы.** Добавить варианты карточек «Новинка» и «Скидка»: использовать Bootstrap `card` и `badge`, а различия задавать собственными модификаторами.
4. **Улучшенная доступность формы.** Добавить постоянные подсказки к полям, связь через `aria-describedby` и текстовые сообщения об ошибках, сохранив корректные подписи и управление с клавиатуры.
