# Канцтовары

## Описание проекта

Учебный интернет-магазин по дисциплине «Фронтенд и бэкенд разработка». В каталоге 16 товаров, включая три ручки и три карандаша с разными характеристиками. Добавлены отдельная карточка товара, корзина и сравнение выбранных товаров. Реализованы фиксированная шапка с общей навигацией, кнопка «Наверх», якорные ссылки, хлебные крошки, фильтры каталога и модальная форма заявки.

Товары и цены демонстрационные. Форма проверяет данные в браузере и показывает учебное подтверждение; реальная отправка на сервер отсутствует.

## Доработки магазина

1. **Расширенный каталог.** 16 товаров, в том числе три ручки и три карандаша. Поиск по названию, категории и диапазону цены; ошибка диапазона, пустой результат и сброс фильтров.
2. **FAQ.** Шесть раскрывающихся вопросов в конце каталога. Используются нативные `details` и `summary`, поэтому ответы доступны без JavaScript и с клавиатуры.
3. **Сравнение характеристик.** На странице товара нажмите «Добавить в сравнение», затем повторите для другого товара. На [странице сравнения](https://uglyfacegoat.github.io/frontend-backend/comparison.html) каждый товар занимает отдельный столбец, а характеристики идут по строкам. Можно выбрать до четырёх товаров, убрать отдельный товар или очистить список. На телефоне таблица прокручивается по горизонтали.
4. **Sticky-фильтр.** На широком экране фильтр закреплён ниже фиксированной шапки. При небольшой высоте экрана содержимое фильтра прокручивается; на телефоне фильтр расположен перед товарами в обычном потоке.

### Отдельные карточки товаров

`product.html?id=pen`, `product.html?id=pen-black` и `product.html?id=pen-red` открывают три разные ручки. Отличаются цвет чернил, толщина линии и механизм. У карандашей `pencil`, `pencil-2b`, `pencil-4b` указаны твёрдость HB, 2B, 4B и наличие ластика. У всех товаров есть свой блок «Характеристики», фотография, описание, цена, кнопки корзины, быстрого заказа и сравнения. Неизвестный идентификатор вызывает сообщение «Товар не найден».

### Корзина и прежняя форма

[Корзина](https://uglyfacegoat.github.io/frontend-backend/cart.html) хранит идентификаторы товаров и количество в `localStorage`. Повторное добавление увеличивает количество. Количество меняется кнопками «−»/«+» или числом от 1 до 99. Сумма пересчитывается; доступны удаление позиции, очистка и пустое состояние. Корзина и список сравнения сохраняются в этом браузере и синхронизируются между вкладками.

«Оформить заявку» в корзине открывает прежнюю модальную форму со списком товаров и суммой. Сохранены имя, e-mail, телефон, дата связи, тема, комментарий и согласие. Прежняя кнопка «Заказать» в карточках тоже работает. Форма только проверяет данные в браузере: реальных заказов и отправки на сервер нет, личные данные не сохраняются.

Главная, контакты, обратная связь, якоря, хлебные крошки, фиксированная шапка, ссылка «Наверх», Flexbox/Grid и классы БЭМ сохранены. Проект остаётся на обычных HTML, CSS и JavaScript, без фреймворков и сборки.

## Как проверить

Для локального просмотра из папки проекта:

```sh
python3 -m http.server 8817 --bind 127.0.0.1
```

Открыть [локальный магазин](http://127.0.0.1:8817/). Для корзины, сравнения, выбранного товара, формы и фильтров нужен JavaScript. Статический каталог, главная, контакты, FAQ и ссылки доступны без него.

После изменения CSS или JavaScript выполните `npm run version-assets`: адреса файлов на всех страницах получат версию по содержимому. Это исключает сочетание нового HTML со старым CSS/JS из браузерного кэша. `npm test` проверяет соответствие версий. `npm run test:styles` отдельно воспроизводит старый CSS в кэше и проверяет оформление каталога, sticky-фильтр, FAQ, кнопку «Наверх», корзину и сравнение на десктопе.

Браузерные проверки (Node.js 20 или новее, в другом терминале):

```sh
npm ci
npx playwright install chromium
npm test
```

Тесты проверяют прежнюю навигацию и полную форму, шесть страниц на ширинах 320, 390, 768 и 1440 px, все 16 карточек товара, фильтры, корзину и сумму, сохранение и очистку, сравнение ручек и карандашей, горизонтальную прокрутку таблицы, FAQ с клавиатуры и sticky-фильтр. `TEST_BASE_URL` задаёт другой адрес, `TEST_OUTPUT_DIR` — папку скриншотов, `CHROME_PATH` — путь к установленному браузеру.
