1. **Для чего используется Flexbox?**

   **Ответ:** Flexbox раскладывает элементы преимущественно вдоль одной оси и выравнивает их.

2. **Для чего используется CSS Grid?**

   **Ответ:** Grid создаёт двумерную сетку строк и столбцов.

3. **Чем Flexbox отличается от Grid?**

   **Ответ:** Flexbox управляет основным направлением и выравниванием внутри строки или колонки; Grid одновременно задаёт строки и столбцы и размещение по сетке.

4. **В каких случаях лучше использовать Flexbox?**

   **Ответ:** Для меню, ряда кнопок и вертикальной структуры карточки.

5. **В каких случаях лучше использовать Grid?**

   **Ответ:** Для сетки карточек и общей структуры каталога с фильтрами и списком товаров.

6. **Что делает display: flex?**

   **Ответ:** display: flex превращает элемент в flex-контейнер, а непосредственных детей — во flex-элементы.

7. **Что делает justify-content?**

   **Ответ:** justify-content распределяет свободное пространство по главной оси flex-контейнера.

8. **Что делает align-items?**

   **Ответ:** align-items задаёт выравнивание элементов по поперечной оси.

9. **Для чего используется gap?**

   **Ответ:** gap задаёт промежутки между элементами, не создавая внешних отступов контейнера.

10. **Что делает flex-wrap?**

   **Ответ:** flex-wrap разрешает перенос flex-элементов на дополнительные строки или колонки.

11. **Что делает display: grid?**

   **Ответ:** display: grid превращает элемент в grid-контейнер, а непосредственных детей — в элементы сетки.

12. **Что задаёт grid-template-columns?**

   **Ответ:** grid-template-columns задаёт набор и размеры колонок, например 240px minmax(0, 1fr).

13. **Что означает 1fr?**

   **Ответ:** 1fr — одна доля свободного пространства grid-контейнера после учёта других размеров и промежутков.

14. **Для чего используется repeat()?**

   **Ответ:** repeat повторяет описание треков, например repeat(3, 1fr) создаёт три одинаковые колонки.

15. **Для чего используется minmax()?**

   **Ответ:** minmax задаёт нижнюю и верхнюю границы размера трека, например minmax(240px, 1fr).

16. **Что такое grid-template-areas?**

   **Ответ:** grid-template-areas описывает сетку через имена областей, здесь "filters products".

17. **Для чего используется grid-area?**

   **Ответ:** grid-area связывает элемент с именованной областью или задаёт его положение в сетке.

18. **Почему в проекте можно одновременно использовать Flexbox и Grid?**

   **Ответ:** Разные части интерфейса решают разные задачи: Grid строит каталог, Flexbox выравнивает меню и содержимое карточек.

19. **Почему адаптивная вёрстка вынесена в отдельную практическую работу?**

   **Ответ:** Сначала изучаются оси и треки; медиазапросы и поведение на устройствах — отдельная тема. В текущем результате дополнительно предусмотрена базовая узкая раскладка.

20. **Почему БЭМ-рефакторинг выполняется отдельно?**

   **Ответ:** Именование компонентов — самостоятельная тема, которая не определяет выбор Flexbox или Grid.
