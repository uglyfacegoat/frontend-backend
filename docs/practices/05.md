1. **Что такое многостраничный сайт?**

   **Ответ:** Многостраничный сайт состоит из нескольких HTML-документов с общими навигацией и оформлением.

2. **Чем ссылка на HTML-страницу отличается от якорной ссылки?**

   **Ответ:** catalog.html открывает другой документ; #popular переводит к элементу текущего документа с id="popular".

3. **Для чего используется атрибут id?**

   **Ответ:** id задаёт уникальный идентификатор для якорей, связи label с input, ARIA-связей и поиска через JavaScript.

4. **Как создать ссылку на раздел текущей страницы?**

   **Ответ:** Создать элемент с id="popular" и ссылку href="#popular".

5. **Как создать ссылку на раздел другой страницы?**

   **Ответ:** Использовать href="index.html#popular": сначала открывается документ, затем его раздел.

6. **Почему навигация должна быть единой на всех страницах?**

   **Ответ:** Пользователь на любой странице видит те же разделы и понимает, как вернуться. Ссылки на якоря внутренних страниц включают index.html.

7. **Для чего используется тег nav?**

   **Ответ:** nav семантически обозначает основную или дополнительную навигацию, в том числе хлебные крошки.

8. **Почему на странице должен быть только один тег main?**

   **Ответ:** Одна видимая main выделяет основное содержимое текущей страницы для навигации и вспомогательных технологий.

9. **Для чего нужны хлебные крошки?**

   **Ответ:** Хлебные крошки показывают положение страницы в структуре и путь к родительской странице.

10. **Почему текущую страницу в хлебных крошках лучше делать через span, а не через ссылку?**

   **Ответ:** Текущая страница уже открыта; span с aria-current="page" обозначает её без лишней ссылки на саму себя.

11. **Для чего нужен уникальный title?**

   **Ответ:** Уникальный title помогает различать вкладки, историю и документы в поисковой выдаче.

12. **Для чего нужен meta name="description"?**

   **Ответ:** meta description кратко описывает документ; поисковая система может использовать описание в сниппете, но не обязана.

13. **Что делает свойство scroll-behavior: smooth?**

   **Ответ:** scroll-behavior: smooth задаёт плавную прокрутку для программных и якорных переходов; здесь отключён при prefers-reduced-motion.

14. **Что делает псевдокласс :target?**

   **Ответ:** :target выбирает элемент, id которого совпадает с фрагментом URL, и помогает выделить место перехода.

15. **Почему дополнительные SEO-элементы лучше выполнять после базовой структуры страниц?**

   **Ответ:** Сначала нужны реальные страницы и работающие ссылки; метаданные не исправят отсутствующее содержимое и нарушенную структуру.
